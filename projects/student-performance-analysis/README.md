# Анализ успеваемости студентов

Python-проект по анализу синтетического набора учебных данных.

Цель проекта — загрузить данные из CSV, рассчитать основные показатели успеваемости, определить студентов группы риска и сформировать итоговые таблицы и графики.

## Стек

- Python;
- pandas;
- matplotlib;
- pytest.

## Что анализируется

В датасете используются:

- идентификатор студента;
- учебная группа;
- посещаемость;
- количество выполненных домашних заданий;
- оценки по математике;
- программированию;
- физике;
- английскому языку.

## Что делает программа

1. Загружает CSV.
2. Проверяет наличие обязательных столбцов.
3. Рассчитывает среднюю оценку каждого студента.
4. Определяет группу риска.
5. Группирует данные по учебным группам.
6. Рассчитывает:
   - количество студентов;
   - среднюю успеваемость;
   - среднюю посещаемость;
   - количество студентов группы риска.
7. Создаёт итоговые CSV-файлы.
8. Строит графики.

## Критерий группы риска

Студент относится к группе риска, если:

- средняя оценка ниже `65`;

или

- посещаемость ниже `75%`.
