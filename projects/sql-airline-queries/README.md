# SQL: анализ данных авиаперевозок

Учебный SQL-проект для практики запросов к реляционным данным авиаперевозок.

В файле `requests.sql` находится **70 SQL-запросов** различной сложности.

## Данные

Используются сущности:

- самолёты;
- клиенты;
- билеты;
- рейсы.

Исходные учебные данные находятся в файлах:

```text
airliners.txt
clients.txt
tickets.txt
trips.txt
```

## Темы

В запросах используются:

- `SELECT`;
- `WHERE`;
- `IN`;
- `BETWEEN`;
- `LIKE`;
- `NULL`;
- `ORDER BY`;
- `DISTINCT`;
- `CASE`;
- `COALESCE`;
- строковые функции;
- арифметические выражения;
- агрегатные функции;
- `GROUP BY`;
- `HAVING`;
- подзапросы;
- `JOIN`.

## Примеры задач

В проекте решаются задачи на:

- фильтрацию самолётов по дальности;
- поиск рейсов по статусу;
- анализ стоимости билетов;
- классификацию самолётов через `CASE`;
- обработку отсутствующих значений;
- объединение клиентов, билетов и рейсов;
- агрегирование результатов.

## Главный файл

```text
requests.sql
```

## Что показывает проект

Проект демонстрирует базовые и промежуточные навыки SQL, необходимые для:

- анализа данных;
- Python/backend-разработки;
- работы с реляционными базами данных.
